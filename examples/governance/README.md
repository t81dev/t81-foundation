# Governance and Axion Kernel

This directory contains examples for the Axion Governance Kernel. It demonstrates how T81 applies deterministic policy rules and policy language (APL) traces to executing operations.

Run the basic bash script inside `governance-demo/` or use standard build steps to compile and run the C++ host files tracking Axion evaluation boundaries.

```bash
cd governance-demo && ./run_governance_demo.sh
```
