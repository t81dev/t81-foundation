# T81Lang In-Browser Playground

A self-contained WebAssembly demo of T81Lang — the balanced ternary language
targeting the T81 Foundation VM.  Users can write and run T81Lang programs
directly in the browser without installing anything.

## Architecture

```
tools/playground/
  src/
    wasm_api.cpp        Emscripten-exported C++ wrapper (t81_run)
  web/
    index.html          Single-page playground UI
    playground.js       Wasm glue, editor, sample programs
    style.css           Dark theme styling
    t81vm.js            ← generated by Emscripten (not in repo)
    t81vm.wasm          ← generated by Emscripten (not in repo)
  CMakeLists.txt        Emscripten build target
  README.md             This file
```

The C++ entry point (`t81_run`) calls into:
- `t81::cli::build_program_from_source()` — full lex → parse → semantic → IRGen → BinaryEmitter pipeline
- `t81::vm::make_interpreter_vm()` — deterministic TISC interpreter

It captures `std::cerr` (diagnostics) and `vm->state().printed_output` (program
output) and returns a JSON string `{"ok":bool,"output":"...","errors":"..."}`.

The web UI uses [CodeMirror 6](https://codemirror.net/) (loaded via CDN) for
editing and renders output/diagnostics in a split pane.

## Building

### Prerequisites

1. [Emscripten SDK](https://emscripten.org/docs/getting_started/downloads.html) — install and activate:
   ```sh
   source /path/to/emsdk/emsdk_env.sh
   ```

2. The repo must be buildable on your host (CMake 3.16+, C++20 compiler).

### Compile

```sh
# From the repo root:
emcmake cmake -B build-wasm -S . \
  -DCMAKE_BUILD_TYPE=Release \
  -DT81_BUILD_PLAYGROUND=ON \
  -DT81_BUILD_TESTS=OFF \
  -DT81_BUILD_EXAMPLES=OFF \
  -DT81_BUILD_BENCHMARKS=OFF

cmake --build build-wasm --target t81_playground -j$(nproc)
```

### Run locally

Copy the generated Wasm files next to the web assets:
```sh
cp build-wasm/tools/playground/t81vm.js   tools/playground/web/
cp build-wasm/tools/playground/t81vm.wasm tools/playground/web/
```

Serve the web directory (a local HTTP server is required because browsers block
`file://` Wasm loads):
```sh
cd tools/playground/web
python3 -m http.server 8080
# Open http://localhost:8080
```

## Sample programs

The playground ships eight built-in samples selectable from the dropdown:

| Sample | Demonstrates |
|--------|-------------|
| Hello, World! | Basic print |
| BigInt Arithmetic | `T81BigInt`, ternary literals (`42t81`) |
| If / Else | Conditional branching |
| Match / Option | Pattern matching, `Option[T]` |
| Symbol Equality | `:alpha` symbol literals |
| Tensor Vec-Add | `std.tensor.from_list`, `vec_add` |
| Agent / Behavior | RFC-0015 agent declarations |
| Bounded Loop | `@bounded(N)` loop annotation |

## Development notes

- **No build step for the web UI** — `index.html` loads CodeMirror 6 via
  `esm.sh` CDN for zero-friction development.  For production, bundle the JS
  locally with Vite or esbuild.
- **SIMD paths are disabled** — `T81_DISABLE_AVX2=1` and `T81_DISABLE_NEON=1`
  are set in the Emscripten target so platform-specific intrinsics compile out.
- **Memory limits** — Initial heap: 64 MB; maximum: 512 MB (growable).
  Stack: 4 MB.  Suitable for programs that do not load large model weights.
- **Max steps** — Programs are capped at 500 000 TISC instructions per run
  to prevent browser hangs.  Increase `kMaxSteps` in `wasm_api.cpp` if needed.
