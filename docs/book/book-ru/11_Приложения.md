## 11.1 Что еще не реализовано

**Статус: Отслеживание**

Хотя базовая T81VM и TISC ISA стабильны, несколько продвинутых функций находятся в стадии активной разработки или исследований.

### 11.1.1 Фаза 2: Полное покрытие `dmath`
В настоящее время `dmath` предоставляет детерминированные реализации для базовой арифметики (`+`, `-`, `*`, `/`) и ключевых трансцендентных функций (`sin`, `cos`, `exp`, `log`).
*   **Отсутствует**: Обратные тригонометрические функции (`asin`, `acos`, `atan`) в настоящее время полагаются на `libc` хоста (если не установлен `T81_DETERMINISTIC`, который вызывает ловушку).
*   **Отсутствует**: Гиперболические функции (`sinh`, `cosh`, `tanh`) реализованы частично.
*   **План**: Реализовать полные разложения в ряды Тейлора/Маклорена для всех стандартных математических функций в `include/t81/core/detail/dmath.hpp`, чтобы устранить все зависимости от `libm`.

### 11.1.2 Фаза 3: Распределенный консенсус (Уровень 4)
Опкоды Уровня 4 (`Gossip`, `Merge`) специфицированы, но лежащий в основе сетевой стек P2P является экспериментальным.
*   **Отсутствует**: Надежное обнаружение пиров (DHT).
*   **Отсутствует**: Механизм защиты от Sybil-атак (заполнитель Proof of Work/Stake).
*   **План**: Интегрировать сетевой уровень с адресацией по содержимому (например, libp2p или кастомный Kademlia) для поддержки децентрализованного слияния состояний.

### 11.1.3 Фаза 4: Полные бесконечные формы (Уровень 5)
Уровень 5 поддерживает базовое схлопывание геометрических рядов.
*   **Отсутствует**: Общее аналитическое продолжение для негеометрических рядов.
*   **Отсутствует**: Символьное суммирование более сложных производящих функций.
*   **План**: Расширить `InfCollapse` для обработки более широкого класса мероморфных функций.

## 11.2 Глоссарий

| Термин | Определение |
| :--- | :--- |
| **Axion** | Ядро безопасности T81, ответственное за применение политик и ведение журнала аудита. |
| **CanonRef** | Каноническая ссылка (хэш SHA3-256), указывающая на неизменяемый объект в CanonFS. |
| **Когнитивный уровень** | Уровень вычислительной способности (1=Символьный до 5=Бесконечный). |
| **Гейт детерминизма** | Процесс CI (`t81lang_repro_gate`), который проверяет побитовую воспроизводимость компилятора. |
| **dmath** | Библиотека детерминированной математики; программная реализация арифметики с плавающей запятой. |
| **T81Float** | Сбалансированное троичное число с плавающей запятой $(s, m, e)$. |
| **T81Int** | Сбалансированное троичное целое число произвольной точности. |
| **TISC** | Ternary Instruction Set Computer; язык байткода T81VM. |
| **Трит** | Цифра по основанию 3 $\{-1, 0, 1\}$. |
| **Трайт** | Последовательность тритов (обычно 4). |
| **Структурная честность** | Принцип, согласно которому система не должна синтезировать информацию или скрывать аппроксимацию. |
