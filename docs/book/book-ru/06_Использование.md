## 6.1 Интерфейс командной строки T81

**Статус: Реализовано**

Бинарный файл `t81` — это основная точка входа для взаимодействия с рантаймом. Он следует стандартному шаблону подкоманд (`subcommand`).

### 6.1.1 Компиляция (`compile`)
Компилирует исходный код T81 (`.t81`) в байткод TISC (`.tisc`).

```bash
t81 compile main.t81 -o main.tisc
```

**Опции**:
*   `-o, --output <file>`: Путь к выходному байткоду.
*   `--policy <file>`: Прикрепить политику Axion к байткоду (встроенную).

### 6.1.2 Выполнение (`run`)
Выполняет файл байткода TISC или исходный файл (JIT-компиляция и запуск).

```bash
# Запустить байткод
t81 run main.tisc

# Запустить исходный код напрямую
t81 run main.t81
```

**Опции**:
*   `--policy <file>`: Принудительно применить файл политики Axion во время выполнения.
*   `--weights <file>`: Прикрепить тензорную модель (`.t81w`, `.safetensors`, `.gguf`) к контексту.

### 6.1.3 Анализ трассировки (`trace`)
Набор подкоманд `trace` управляет журналами аудита Axion.

*   `t81 trace show <trace_file>`: Читаемый человеком дамп трассы.
*   `t81 trace diff <trace_a> <trace_b>`: Сравнение двух трасс на предмет расхождений.
*   `t81 trace replay <program.tisc> <trace_file>`: Повторное выполнение программы и проверка, что она производит точно такую же трассу, как в файле.

### 6.1.4 Интерактивный режим (`repl`)
Запускает цикл Чтение-Вычисление-Печать (REPL).

```bash
t81 repl
```
Команды внутри REPL:
*   `:load <file>`: Загрузить скрипт.
*   `:model <path>`: Динамически загрузить файл весов.
*   `:trace`: Показать трассу последнего выполнения.

## 6.2 Встраивание T81 (C++ API)

**Статус: Стабильно**

Чтобы встроить T81 в хост-приложение (например, игровой движок или распределенный узел), используйте `t81::vm::IVirtualMachine`.

```cpp
#include <t81/vm/vm.hpp>
#include <t81/isa/program.hpp>

int main() {
    // 1. Создать VM
    auto vm = t81::vm::make_interpreter_vm();

    // 2. Загрузить программу
    auto prog = t81::tisc::load_program("main.tisc");
    vm->load_program(prog);

    // 3. Настроить политику
    // (Опционально: Прикрепить пользовательские хуки Axion)

    // 4. Запустить
    auto result = vm->run_to_halt();
    if (!result) {
        std::cerr << "Trapped: " << result.error().reason << "\n";
    }
}
```

## 6.3 Встраивание T81 (Python API)

**Статус: Реализовано**

Привязки Python позволяют управлять T81VM из Python, в первую очередь для тестирования и оркестрации.

```python
import t81

# Создать VM
vm = t81.VirtualMachine()

# Загрузить код
vm.load_source("""
let x = 10;
let y = 20;
x + y;
""")

# Выполнить
result = vm.run()
print(f"Result: {result}")
```

## 6.4 Отладка

**Статус: Реализовано**

Команда `t81 debug` запускает отладчик в стиле GDB для TISC.

*   `step` / `s`: Шаг на одну инструкцию.
*   `next` / `n`: Шаг через вызов.
*   `reg`: Дамп регистров.
*   `stack`: Дамп стека.
*   `trace`: Показать недавнюю историю трассы.

```bash
t81 debug main.tisc
(t81-gdb) break 10
(t81-gdb) run
Точка останова на PC=10
(t81-gdb) reg r1
r1 = 42 (Int)
```
