## 11.1 尚未实现的功能

**状态：跟踪中**

虽然核心 T81VM 和 TISC ISA 是稳定的，但一些高级功能仍处于积极开发或研究阶段。

### 11.1.1 第二阶段：完全 `dmath` 覆盖
目前，`dmath` 为基本算术（`+`, `-`, `*`, `/`）和关键超越函数（`sin`, `cos`, `exp`, `log`）提供了确定性实现。
*   **缺失**：反三角函数（`asin`, `acos`, `atan`）目前依赖于主机 `libc`（除非设置了 `T81_DETERMINISTIC`，这会导致陷阱）。
*   **缺失**：双曲函数（`sinh`, `cosh`, `tanh`）是部分的。
*   **计划**：在 `include/t81/core/detail/dmath.hpp` 中为所有标准数学函数实现完整的泰勒/麦克劳林级数展开，以移除所有 `libm` 依赖。

### 11.1.2 第三阶段：分布式共识 (第 4 层)
第 4 层操作码（`Gossip`, `Merge`）已指定，但底层的 P2P 网络栈是实验性的。
*   **缺失**：健壮的对等点发现 (DHT)。
*   **缺失**：女巫攻击抵抗机制（工作量证明/权益证明占位符）。
*   **计划**：集成内容寻址网络层（例如 libp2p 或自定义 Kademlia）以支持去中心化状态合并。

### 11.1.3 第四阶段：完全无限形式 (第 5 层)
第 5 层支持基本的几何级数坍缩。
*   **缺失**：非几何级数的通用解析延拓。
*   **缺失**：更复杂生成函数的符号求和。
*   **计划**：扩展 `InfCollapse` 以处理更广泛的亚纯函数类。

## 11.2 术语表

| 术语 | 定义 |
| :--- | :--- |
| **Axion** | T81 的安全内核，负责策略强制和审计日志记录。 |
| **CanonRef** | 指向 CanonFS 中不可变对象的规范引用（SHA3-256 哈希）。 |
| **Cognitive Tier** | 计算能力的层级（1=符号到 5=无限）。 |
| **Determinism Gate** | 验证编译器的位精确可重现性的 CI 过程 (`t81lang_repro_gate`)。 |
| **dmath** | 确定性数学库；浮点算术的软件实现。 |
| **T81Float** | 平衡三进制浮点数 $(s, m, e)$。 |
| **T81Int** | 任意精度平衡三进制整数。 |
| **TISC** | 三进制精简指令集计算机；T81VM 的字节码语言。 |
| **Trit** | base-3 数字 $\{-1, 0, 1\}$。 |
| **Tryte** | 一系列 trits（通常为 4 个）。 |
| **Structural Honesty** | 系统不得合成信息或隐藏近似值的原则。 |
