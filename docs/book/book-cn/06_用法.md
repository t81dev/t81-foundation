## 6.1 T81 命令行接口

**状态：已实现**

`t81` 二进制文件是与运行时交互的主要入口点。它遵循标准的 `subcommand` 模式。

### 6.1.1 编译 (`compile`)
将 T81 源代码 (`.t81`) 编译为 TISC 字节码 (`.tisc`)。

```bash
t81 compile main.t81 -o main.tisc
```

**选项**：
*   `-o, --output <file>`：输出字节码路径。
*   `--policy <file>`：将 Axion 策略附加到字节码（嵌入）。

### 6.1.2 执行 (`run`)
执行 TISC 字节码文件或源文件（JIT 编译并运行）。

```bash
# 运行字节码
t81 run main.tisc

# 直接运行源代码
t81 run main.t81
```

**选项**：
*   `--policy <file>`：在执行期间强制执行特定的 Axion 策略文件。
*   `--weights <file>`：将张量模型 (`.t81w`, `.safetensors`, `.gguf`) 附加到上下文。

### 6.1.3 追踪分析 (`trace`)
`trace` 子命令套件管理 Axion 审计日志。

*   `t81 trace show <trace_file>`：以人类可读格式转储追踪。
*   `t81 trace diff <trace_a> <trace_b>`：比较两个追踪的差异。
*   `t81 trace replay <program.tisc> <trace_file>`：重新执行程序并验证其产生与文件完全相同的追踪。

### 6.1.4 交互模式 (`repl`)
启动“读取-求值-打印”循环 (REPL)。

```bash
t81 repl
```
REPL 内的命令：
*   `:load <file>`：加载脚本。
*   `:model <path>`：动态加载权重文件。
*   `:trace`：显示最后一次执行的追踪。

## 6.2 嵌入 T81 (C++ API)

**状态：稳定**

要将 T81 嵌入到宿主应用程序（例如游戏引擎或分布式节点）中，请使用 `t81::vm::IVirtualMachine`。

```cpp
#include <t81/vm/vm.hpp>
#include <t81/isa/program.hpp>

int main() {
    // 1. 创建 VM
    auto vm = t81::vm::make_interpreter_vm();

    // 2. 加载程序
    auto prog = t81::tisc::load_program("main.tisc");
    vm->load_program(prog);

    // 3. 配置策略
    // (可选：附加自定义 Axion 钩子)

    // 4. 运行
    auto result = vm->run_to_halt();
    if (!result) {
        std::cerr << "Trapped: " << result.error().reason << "\n";
    }
}
```

## 6.3 嵌入 T81 (Python API)

**状态：已实现**

Python 绑定允许从 Python 驱动 T81VM，主要用于测试和编排。

```python
import t81

# 创建 VM
vm = t81.VirtualMachine()

# 加载代码
vm.load_source("""
let x = 10;
let y = 20;
x + y;
""")

# 执行
result = vm.run()
print(f"Result: {result}")
```

## 6.4 调试

**状态：已实现**

`t81 debug` 命令启动 TISC 的 GDB 风格调试器。

*   `step` / `s`：单步执行一条指令。
*   `next` / `n`：单步跳过调用。
*   `reg`：转储寄存器。
*   `stack`：转储栈。
*   `trace`：显示最近的追踪历史。

```bash
t81 debug main.tisc
(t81-gdb) break 10
(t81-gdb) run
Breakpoint at PC=10
(t81-gdb) reg r1
r1 = 42 (Int)
```
