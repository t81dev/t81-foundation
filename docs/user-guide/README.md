# User Guide

This directory contains documentation for users of the T81 Foundation.

## Structure

- **getting-started/** - Quickstart guides for new users
- **tutorials/** - Step-by-step tutorials for common tasks
- **how-to/** - Practical guides for specific operations
- **reference/** - Reference documentation and API docs

## Quick Start

New users should start with [getting-started/ai-quickstart.md](getting-started/ai-quickstart.md) for AI agents or [getting-started/cpp-quickstart.md](getting-started/cpp-quickstart.md) for C++ developers.
