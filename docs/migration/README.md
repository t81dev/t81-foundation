# T81 docs/migration

Notes in this directory explain published compatibility text and open review
questions. They do not accept an RFC, change a frozen specification, bump a
version, or authorize a release.

- [C++ SDK 1.x to 2.x](cpp-sdk-1x-to-2x.md) — non-normative companion to draft
  RFC-00E9. It records the published v2.0.0 consumer notes, the historical
  source checklist, and the checks that remain open.
