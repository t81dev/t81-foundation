**Date:** 2026-11-19  
**Tag:** `v2.1.0` (`9ddeeccda`)

T81 Foundation `v2.1.0` consolidates the native C++ Model Context Protocol (MCP) server, Dual-Rail `(P, N)` bitplane `TMatMul` execution inside `T81VM` (ARM64 NEON + x86_64 AVX2) with `CanonFS` `SBDR1T2D` direct weight caching, `BF16`/`SBDR1T2D` Safetensors ingestion, and strict CI/governance hardening.

T81 remains an experimental computing architecture and systems research platform. This release does not establish production readiness, universal ternary superiority, or physical ternary hardware advantages beyond the tested software surfaces.

## Key Capabilities Added Since `v2.0.0`

- **Hardened 15-Tool Native C++ MCP Server (`t81 mcp serve`):**
  - Replaced substring JSON scanning with `ScopedJsonParser` (nesting depth capped at `64`, exact JSON-RPC `id` preservation, `ERANGE` and leading-whitespace rejection on numeric arguments), standard MCP `content` + `isError` envelopes, notification silence, and `ping`.
  - Added `t81.verify_subgraph` (#11), `t81.diff_check` (#13, Hamming flip-budget gate), `t81.memory_search` (#14, zero-float deterministic Dual-Rail RAG), `t81.adapter_apply` (#15, zero-dequantization saturated ternary adapter composition supporting dense and canonical `SBDR1` with atomic writes), and fail-closed `VM_TRAP` handling in `t81.run_subgraph`.
  - Verified via `examples/research/agent-receipt-sidecar/test_native_mcp.py` (`15/15` tools, `~0.118 ms` mean warm `gate_check`).
- **`T81VM` Dual-Rail `(P, N)` `TMatMul` & `CanonFS` `SBDR1T2D` Integration:**
  - Wired ARM64 NEON (`vcntq_u8` + `vpadalq_u8`) and x86_64/MSVC AVX2 (`#elif defined(__AVX2__)`) Dual-Rail popcount into `Opcode::TMatMul` with 64/128-trit block-zero activation skipping and accurate `ExactTrit` / `ExactInt` / `HostFloat` numeric-class propagation.
  - Added content-hash-keyed `CanonDualRailRhsCache` and direct `SBDR1T2D` loading in `Opcode::TLoadHash`, with cache invalidation across VM reset, in-place `Opcode::TSet`, and GC reclamation (covered by CTest `t81_dualrail_sbdr_vm_test`).
  - Full-stack `CanonFS → Axion → TISC → T81VM → DualRail` pipeline verified bit-exact against an independent oracle with fail-closed `SecurityFault` on unauthorized tensor access (`examples/research/full-stack-t81-pipeline/run_pipeline.sh`).
- **BitNet Safetensors Ingester (`examples/research/bitnet-verifiable-token/load_safetensors_bitnet.py`):**
  - Added `BF16` decoding, per-tensor `absmean_gamma`, `--emit-sbdr` (`SBDR1`), and `--emit-sbdr2d` (`SBDR1T2D`), verified on `models/tiny-random-llama-exported.safetensors` (`21` tensors, `1,032,272` trits, `4.0×` vs `I8`).
- **CLI, Packaging, & Governance:**
  - Grouped `t81 --help` into 5 thematic sections, added `t81 help mcp` / `t81 mcp help`, updated `bash`/`zsh`/`fish` completions, manpage, and CLI user manual (§4.26), verified by `scripts/ci/check_cli_docs_parity.py` (`24` topics).
  - Synced `CMakeLists.txt`, `pyproject.toml`, `include/t81/config.hpp`, `mcp_server.cpp` (`T81_VERSION_STR`), and `docs/governance/PUBLIC_API_LOCK.json` to `2.1.0`.
  - Unmasked CI governance checks with `set -euo pipefail` (`18/18` governance scripts passing).

## Preserved Research Boundaries & Negative Findings

- **Preserved Holds:** `RFC-00D7-F01` (`M1–M6 STOP`), `SCG-08` Gate 2 (`NO-GO`), `H01` / Investigation 10A (`BLOCKED`), and `AXION-AI-001` (`HD01–HD06` open) remain unchanged.
- **Preserved Negative Results:**
  - **Harley-Seal 3:2 CSA on Apple Silicon:** Loses to direct NEON popcount (`0.57×` on M2; independently reproduced on Apple M5 in Issue #555).
  - **`INT4 × Ternary` 4-Plane Bit-Sliced Kernel (Apple M2):** `1.42×` vs NEON `vdotq_s32` on decode `1×4096×4096` (below `1.50×` falsifier) and `0.83×` (slower) on compute-bound `256×512×256` prefill; Dual-Rail popcount's compute advantage over `vdotq_s32` is scoped to 2-plane ternary activations (`1.8×–2.3×`), not 4-plane `INT4`.
  - **1-Stage Ternary KV-Cache Attention (`D=128`):** Suffers integer tie collisions (`18.2%–40.6%` Recall@10).
  - **Dense Ternary VSA (`D=10,240`):** Ties fair 1-bit Binary VSA on dense random capacity at `2×` RAM.
