# Release v2.0.0

**Date:** 2026-11-17  
**Tag:** `v2.0.0` (release candidate qualification on `main`)

T81 Foundation `v2.0.0` aligns project packaging, public API version metadata, SDK header installation, and deterministic runtime/interchange hardening into a single major-version baseline.

T81 remains an experimental computing research platform. This release does not establish production readiness, native ternary hardware advantage, or broader determinism guarantees beyond the tested surfaces.

## Compatibility and Breaking Changes

- **Version & Public API Baseline (`2.0.0`):** `CMakeLists.txt`, `pyproject.toml`, `include/t81/config.hpp`, and `PUBLIC_API_LOCK.json` are aligned to `2.0.0`.
- **CanonFS Persistent Stores:** Portable storage uses `h1-` lowercase-hex filename components and `.canonfs-format = t81-canonfs-hex-v1`. Unmarked nonempty legacy stores are rejected with an explicit migration error; back up stores and capability metadata before migrating.
- **Bytecode & C++ ABI:** Extension/vector/FFI opcode assignments and `T81Fraction` exception-safety/class layouts changed relative to `v1.9.4`. Recompile bytecode artifacts and C++ consumers against matched `v2.0.0` headers and libraries.
- **Policy Hooks:** `AxionVerdict` defaults to deny; policy hooks must return an explicit allow verdict after checks.

## Key Engineering & Hygiene Changes

- **VM & Runtime Hardening:** Integer arithmetic UB guards and Tier 6 rank mapping (`#798`), `--canonfs-root` CLI contract isolation and `canonfs export --policy-profile` negative testing (`#830`).
- **SDK & Packaging Hygiene:** Excluded `config.hpp.in` and `config.hpp.backup` from `cmake --install` header trees (`#832`), fixed `Dockerfile` script copy path (`#829`), and aligned GitHub Actions / CodeQL pins (`#832`).
- **Documentation & Governance:** Consolidated root research/capabilities reports into `docs/research/` (`#833`), reconciled `CURRENT_STATE.json` and `START_HERE.md` (`#830`), and added non-publishing `workflow_dispatch` dry-run guards to release/wheel/Docker workflows (`#833`, Batch 5).

## Research Boundaries

- **Preserved Holds:** `RFC-00D7-F01` remains at `M1–M6 STOP`, `SCG-08` Gate 2 remains `NO-GO`, and canonical `H01–H08` identities and Hanoi/CWEB lineage are preserved.
