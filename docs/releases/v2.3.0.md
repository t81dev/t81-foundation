## Highlights

### 1. M3 Python SDK Governed Execution & Native Ed25519 Primitives (`#887`)
- Added `ProviderGovernor`, `T81VmProvider`, `ControlledProvider`, `ed25519_generate_keypair`, `sign_rfc00d4_payload`, and `verify_dag` to the `t81` Python SDK (`ffi/python/t81/__init__.py`, `CPython 3.9–3.14` wheels across Linux, macOS, and Windows).
- Added `AcceleratorBackend` abstraction and verified installed SDK bindings across all wheel targets (`tests/python/test_installed_sdk.py`).

### 2. Native C++23 RFC 8032 / Wycheproof Ed25519 Receipts & Offline Bundles (`#887`, `#897`, `#901`)
- Implemented native C++23 RFC 8032 Ed25519 signing, verification, and `verify_dag` under `src/crypto/ed25519_bundle.cpp` (cross-compiler verified on Apple Clang, Linux GCC/Clang, and Windows MSVC/`clang-cl`; UBSan/ASan clean).
- Added Wycheproof canonical `y < p = 2^255 - 19` checks and fail-closed rejection of all 8 Ed25519 small-order torsion points for both `A` and `R` (`t81_ed25519_bundle_test`).
- Added `t81 receipt export` for atomic, offline-verifiable Ed25519 forensic bundles (`t81_kev_and_receipt_bundle_test`).

### 3. DPE + MCP Transactional Airlock, KEV Containment & Three-Plane Contract (`#888`, `#897`, `#901`)
- Unified `DpeMcpCoordinator` (`tx_begin` / `tx_commit` / `tx_abort`) with the 15-tool native C++ MCP server (`t81 mcp serve`, `RFC-00D8`, `--root` jail), formally verified in TLA+ (`spec/formal/TernaryOSTransactions.tla` — `DpeBatchCommit` and `PlaneTransitionInvariant`, `0` errors).
- Added fail-closed KEV/advisory MCP gating (`ERR_KEV_ADVISORY_BLOCKED`, `DEFER_ADVISORY_REVIEW`, `ERR_MANIFEST_DIGEST_MISMATCH`).
- Codified the Three-Plane stratified transition contract (`source_plane`, `target_plane`, `transition_kind`, `reproducibility_class`, `hybrid_reconciled`, `state_a_ref`, `ERR_PLANE_BYPASS_DENIED`) and updated `provider-evidence-v1.schema.json` with the strict `plane_transition` schema (`t81_provider_schema_conformance_test`).
- Added cross-platform differential oracles (`tests/determinism/cross_platform_differential_test.py` and `tests/determinism/three_plane_differential_test.py`).

### 4. BitNet-2B Streaming Ingestion & Apple M2 `R3` Dispatch (`#887`, `#898`)
- Added `--chunk-bytes` streaming ingestion to `examples/research/bitnet-verifiable-token/load_safetensors_bitnet.py` (`4.0×` vs INT8 storage) and the H06-MEM-04 Apple M2 `R3` dispatch receipt (`docs/records/status-history/BITNET_2B_DISPATCH_AND_STREAMING_RECEIPT_2026-11-26.md`).

### 5. Experimental Enclave Runner, Blueprint & Governance Hygiene (`#888`, `#896`, `#899`, `#900`, `#851`, `#853`, `#854`, `#902`)
- Added experimental `t81 enclave run` headless AArch64 runner (`Governed non-DCP`, not a general-purpose OS).
- Published [AI_OS_STRATIFIED_BLUEPRINT.md](../architecture/AI_OS_STRATIFIED_BLUEPRINT.md) (`DEC-004`, Horizon D — strictly *Planned / Design Target*; neural OS helpers are not implemented).
- Reconciled `docs/architecture/` (repairing 19 broken relative links) and root docs (`README.md`, `AGENTS.md`, `.cursorrules`, `CONTRIBUTING.md`, `PROJECT_STRUCTURE.md`).
- Landed RFC index & ADR collision hygiene (`#851`, `114` RFCs, `7` ADRs), CI `set -o pipefail` exit-code propagation & `check_architecture_coherence.py` (`#853`), `SCG-08` Gate 1 reproduction audit record (`#854`), Gate 1 `-Wclass-memaccess` warning cleanup (`#859`), and 16 archived historical research reports under `docs/research/archive/` (`#902`).
