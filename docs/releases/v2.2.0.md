## Python SDK

- Reconstruct a CanonFS reference from its saved hex digest or bytes. Use
  `CanonRef.to_cli_handle()` with a separately installed native `t81` CLI to
  verify and retrieve objects directly from the Python-written store.
- VM runs raise `StepLimitExceeded` if the step budget ends before halt. Code
  that uses a step limit to pause execution can catch the exception and
  resume the same VM. `vm.halted` reports the current state. The convenience
  function `compile_and_run()` accepts a keyword-only `max_steps`.
- `vm.axion_events` exposes read-only event snapshots with the opcode, program
  counter, verdict, reason, and reason code. `vm.axion_log` keeps its existing
  reason-string behavior.
- Both dynamic tensor classes reject replacement data with the wrong element
  count before changing the tensor. Fixed-size tensors support negative
  indices. `int()` converts `T81Int` and `BigInt` values to Python integers.
- The Python package overview includes a fixture handoff using the store path
  and handle. The source distribution includes the required C++ emitter.
  Release CI installs the generated source archive and tests the installed SDK
  on every built wheel. The matrix includes standard CPython 3.14 wheels.

See the [Python SDK package overview](../../ffi/python/README.md) for the fixture
example and installation instructions.
