# `docs/proposals`

Design proposals and pre-RFC working documents.

## Purpose
- Capture ideas before they become formal specs or accepted roadmap work.
- Record rationale, alternatives, and migration considerations.

## Suggested Template
- Problem statement
- Goals / non-goals
- Proposed design
- Compatibility and rollout plan
- Open questions

## Lifecycle
- Promote accepted proposals into `spec/` and implementation tasks.
- Move superseded material to `docs/records/archive/`.
