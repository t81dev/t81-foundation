# Process Documentation

This directory contains process documentation for the T81 Foundation project.

## Structure

- **rfcs/** - Request for Comments (RFC) documents
- **proposals/** - Feature proposals and specifications
- **roadmaps/** - Project roadmaps and planning documents
- **policies/** - Project policies and alignment guidelines
- **migration/** - Migration guides and procedures

## Process Overview

All changes to the specification follow the RFC process documented in the **rfcs/** directory.
