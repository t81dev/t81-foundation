## 3. Becoming a Maintainer

Maintainership is earned through consistent, high-quality contributions and community engagement.

1.  **Contribute:** Submit PRs, review code, help others.
2.  **Nominate:** Existing maintainers can nominate new maintainers.
3.  **Vote:** Maintainers vote on the nomination.

See [GOVERNANCE.md](../policies/GOVERNANCE.md) for more details.
