# 第 5 章：安装与构建验证

## 5.1 前置条件

**状态：标准化**

构建 T81 需要一个能够支持 C++23 特性的现代 C++ 工具链。项目强制执行严格的编译器警告和标准合规性，以最大限度地减少未定义行为。

### 支持的平台
*   **Linux**: x86_64, ARM64 (aarch64), RISC-V (rv64gc)
*   **macOS**: Apple Silicon (M1/M2/M3), Intel (旧版)
*   **Windows**: 推荐 WSL2 (MSVC 支持处于实验阶段)

### 工具链要求
*   **编译器**：
    *   Clang 18+（推荐，因其严格性）
    *   GCC 14+
    *   MSVC 19.38+ (VS 2022)
*   **构建系统**：CMake 3.25 或更新版本。
*   **Python**：Python 3.10+（用于验证脚本和绑定）。
*   **Ninja**：推荐用于更快的构建。

## 5.2 从源代码构建

**状态：自动化**

标准的构建过程封装在 `make cmake-ritual` 命令中，但也可以通过 CMake 手动执行。

### 5.2.1 CMake 工作流

```bash
# 1. 克隆仓库
git clone https://github.com/t81-foundation/t81.git
cd t81

# 2. 配置（推荐使用 Release 模式以获得性能）
cmake -B build -G Ninja \
    -DCMAKE_BUILD_TYPE=Release \
    -DT81_USE_CXX23=ON \
    -DT81_BUILD_TESTS=ON

# 3. 构建核心可执行文件
cmake --build build --target t81
```

### 5.2.2 构建选项
以下 CMake 选项控制构建配置：

| 选项 | 默认值 | 描述 |
| :--- | :--- | :--- |
| `T81_USE_CXX23` | `ON` | 启用 C++23 特性（例如 `std::expected`, `std::print`）。 |
| `T81_BUILD_TESTS` | `ON` | 编译验证套件 (`t81_*_test`)。 |
| `T81_BUILD_EXAMPLES` | `ON` | 编译 `examples/` 中的演示程序。 |
| `T81_ENABLE_ASAN` | `OFF` | 启用 AddressSanitizer（仅限 Debug）。 |
| `T81_ENABLE_UBSAN` | `OFF` | 启用 UndefinedBehaviorSanitizer。 |

> **关于确定性的说明**：为了确保严格的确定性（禁用主机 FPU 对超越函数的回退），如果默认未设置，请手动定义 `T81_DETERMINISTIC`：
> `cmake -B build -DCMAKE_CXX_FLAGS="-DT81_DETERMINISTIC"`

## 5.3 验证构建

**状态：关键**

构建完成后，您 **必须** 验证生成的二进制文件是否符合 T81 规范。成功的编译并不能保证正确的执行。

### 5.3.1 运行单元测试
通过 `ctest` 执行标准测试套件。这将运行数百个基于属性的测试。

```bash
cd build
ctest --output-on-failure
```

### 5.3.2 确定性网关
最关键的检查是 **确定性网关 (Determinism Gate)**。此脚本编译一个规范的参考程序，运行它，并将生成的 Axion Trace 哈希与已知良好的值进行比较。

```bash
# 运行重现网关
python3 scripts/ci/t81lang_repro_gate.py --binary ./build/t81
```

**预期输出**：
```text
[PASS] Trace Hash: canon:sha3:a7f92b... MATCHES expected baseline.
[PASS] Cycles: 10420 (Exact match)
[PASS] Determinism verification successful.
```

如果此脚本失败，则构建被 **污染 (tainted)**，不得用于生产或审计任务。

### 5.3.3 验证架构目标
确保构建图与架构规范相匹配：

```bash
python3 scripts/ci/check_architecture_targets.py
```

## 5.4 故障排除

*   **"C++23 not supported"**：升级您的编译器。T81 严重依赖现代 C++ 特性来实现类型安全。
*   **"Trace Hash Mismatch"**：您可能链接到了不同版本的标准库，或者触发了 `dmath` 回退。确保定义了 `T81_DETERMINISTIC`。
*   **"SIMD Instruction Fault"**：T81 尝试检测 AVX2/NEON 的可用性。如果进行交叉编译，请确保目标标志正确。
