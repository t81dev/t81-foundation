# 第 15 章：研究前沿

## 15.1 三进制硬件加速

**状态：研究**

虽然 T81 通过模拟（`packed-trit` 存储）在二进制硬件上高效运行，但原生三进制硬件可能提供显著的优势。
*   **信息密度**：Trits 携带 $\approx 1.58$ 比特的信息。一个 27-trit 字适合 64 位，但表示 $7.6 \times 10^{12}$ 个值，远超过 $2^{32}$。
*   **算术效率**：与二进制相比，平衡三进制加法减少了平均进位操作次数。
*   **能源效率**：研究表明，三进制逻辑门在某些 AI 工作负载（例如稀疏神经网络）中可能更节能。

**前进道路**：
1.  **FPGA 仿真**：将 TISC 核心移植到针对 Xilinx Artix-7 的 Verilog/VHDL，实现原生三进制 ALU。
2.  **ASIC 设计**：与开源芯片项目 (OpenROAD) 合作，流片概念验证三进制协处理器。

## 15.2 形式化验证路径

**状态：研究**

目前，T81 依赖 **基于属性的测试**（QuickCheck 风格）和 **模糊测试** 来确保正确性。下一步是 **形式化证明**。
*   **Coq / Isabelle**：在证明助手中定义 TISC 的形式语义。
*   **认证编译**：证明 T81 编译器保留了从 源代码 $\to$ AST $\to$ IR $\to$ 字节码 的语义。
*   **JIT 正确性**：证明追踪优化通道（常量折叠、死代码消除）是保留语义的变换。

## 15.3 CanonFS 作为 Merkle 基底

**状态：概念**

CanonFS 目前处理静态 blob（权重、代码）。未来的研究旨在使其成为一个完全的 **通过不可变实现可变 (Mutable-via-Immutable)** 的文件系统，类似于 Git 或 IPFS，但针对 AI 工作负载进行了优化。
*   **版本化模型**：`model:v1` 是指向 `hash1` 的指针。`model:v2` 是指向 `hash2` 的指针。
*   **去重**：自动在不同神经网络之间去重层。
*   **懒加载**：按需通过网络流式传输张量切片，并由 Merkle 证明进行验证。

## 15.4 大规模确定性 AI 推理

**状态：积极开发**

T81 的最终目标是 **主权 AI**：确定性地运行大型语言模型 (LLM)。
*   **问题**：当前的 GPU (CUDA) 由于并行规约顺序和硬件怪癖而非确定性。
*   **解决方案**：T81 的 `dmath` 和张量库提供了一个缓慢但正确的参考实现。
*   **优化**：实现确定性并行规约算法（例如，基于树的求和），以允许在不牺牲位精确性的情况下进行多核执行。
*   **应用**：去中心化 AI 网络，其中节点必须就 LLM 提示的输出达成共识。
