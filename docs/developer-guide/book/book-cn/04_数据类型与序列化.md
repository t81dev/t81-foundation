# 第 4 章：数据类型与序列化

## 4.1 原生类型

**状态：已实现并测试**

T81 架构建立在平衡三进制原语的基础之上。这些类型的即被设计为可以在二进制硬件上高效模拟，同时保持 base-3 逻辑的数学属性。

### 4.1.1 Trits 和 Trytes

*   **Trit**：信息的基本原子，取值为 $\{-1, 0, 1\}$。
    *   也表示为 $\{T, 0, 1\}$ 或 $\{-, 0, +\}$。
    *   信息含量：$\log_2 3 \approx 1.58$ 比特。
*   **Tryte**：一系列 trits。标准的“字节等价物”是 4-trit Tryte（$3^4 = 81$ 个值）。
*   **Word**：标准的 T81 机器字是 27 trits ($3^{27} \approx 7.6 \times 10^{12}$)，可以舒适地放入 64 位整数中。

**打包表示 (T3_K)**：
为了高效存储，trits 通常使用 2 位代码打包：
*   `00` $\to$ 0
*   `01` $\to$ 1
*   `10` $\to$ -1 (T)
*   `11` $\to$ 未使用 / 填充

### 4.1.2 T81Int (任意精度整数)
`T81Int` 是一种可变宽度整数类型。与使用补码表示负值的二进制整数不同，平衡三进制整数是对称的。

*   **范围**：对称区间 $[-\frac{3^N-1}{2}, +\frac{3^N-1}{2}]$。
*   **规范化**：在规范序列化形式中严格禁止前导零。零的唯一有效表示是单个 `0` trit。

## 4.2 T81Float 和 dmath

**状态：已实现 (核心)**

浮点算术是跨平台计算中非确定性的主要来源。T81 用完全由软件定义的格式 **`T81Float`** 取代了硬件 IEEE-754 浮点数。

### 4.2.1 规范定义
一个 `T81Float<M, E>` 是一个元组 $(s, m, e)$，表示值：
$$
V = s \times m \times 3^{e - \text{bias}}
$$
其中：
*   $s \in \{-1, 1\}$ 是符号（存储为一个 trit）。
*   $m$ 是尾数，一个 $M$-trit 整数，已规范化使得最高有效 trit 不为零（除非 $V=0$）。
*   $e$ 是指数，一个 $E$-trit 整数。
*   $\text{bias} = \frac{3^E - 1}{2}$。

**特殊值**：
*   **零**：$e = 0, m = 0$。
*   **无穷大**：$e = e_{\max}, m = 0$。
*   **NaE (非实体)**：$e = e_{\max}, m \neq 0$。（等同于 NaN）。

### 4.2.2 dmath 后端
为了保证在 x86、ARM 和 RISC-V 上的位精确结果，T81 实现了 **`dmath`**（确定性数学）。
*   **算术**：`Add`, `Sub`, `Mul`, `Div` 使用尾数上的整数数学实现，并在软件中应用精确的舍入规则（偶数舍入）。
*   **超越函数**：像 `sin`, `cos`, `exp`, `log` 这样的函数使用 **泰勒级数展开** 计算，具有固定的迭代次数和固定的常数精度。这消除了对宿主操作系统 `libm` 的依赖，`libm` 在 glibc、musl 和 MSVC 之间各不相同。

## 4.3 张量与规范布局

**状态：已实现并测试**

张量 (`T81Tensor`) 是认知层的主力。为了支持高效执行和规范哈希，它们遵循严格的布局。

### 4.3.1 内存布局
张量以 **行主序 (Row-Major)** 存储（C 风格），而不是列主序（Fortran 风格）。
*   **形状**：维度向量 $(d_0, d_1, \dots, d_n)$。
*   **步幅**：计算公式为 $s_i = \prod_{j=i+1}^n d_j$。
*   **对齐**：张量数据在 `Tensor` 内存段中对齐到 64 字节边界，以便在安全的情况下促进 SIMD 加载 (AVX-512 / NEON)。

### 4.3.2 序列化 (.t81w)
`.t81w` (T81 Weights) 格式是用于持久化张量模型的标准容器。它被设计为 **mmap 友好** 和 **规范的**。

**二进制结构 (版本 2)**：
1.  **魔数头**：`0x54383157` ("T81W")。
2.  **版本**：`0x02`。
3.  **目录**：`(Hash, Offset, Length)` 元组列表，按 Hash 排序。
4.  **Blob 数据**：连续的张量数据，填充至 64 字节对齐。

### 4.3.3 量化 (T3_K)
T81 支持一种名为 **T3_K** 的原生三进制量化格式。
*   **块大小**：$K$ trits（通常为 64 或 128）。
*   **表示**：每个值被量化为 $\{-1, 0, 1\}$。
*   **缩放**：每个块有一个缩放因子 (T81Float) 来近似原始幅度。

## 4.4 规范序列化规则

**状态：已实现**

为了确保一致的哈希（对于 `CanonRef`），所有数据在序列化之前必须被规范化。序列化器强制执行抽象值和字节序列之间的 **双射映射**。

1.  **整数 (T81Int)**：
    *   去除前导零。
    *   零被编码为单个字节 `0x00`（假设特定编码）。
2.  **浮点数 (T81Float)**：
    *   必须被规范化（最大左移）。
    *   严格禁止负零；必须转换为正零。
    *   NaE 载荷被清零（不区分“信号”与“安静”位）。
3.  **集合**：
    *   **映射/字典**：键必须按其规范二进制表示的字典顺序排序。
    *   **集**：元素必须排序。
4.  **图**：
    *   节点通过规范拓扑排序重新索引。如果图有环，则应用确定性的平局决胜规则（基于边权重）。

> **验证**：`tests/cpp/test_property_invariants.cpp` 通过基于属性的测试 (fuzzing) 验证这些属性，确保 $Serialize(Deserialize(Serialize(X))) \equiv Serialize(X)$。
