# `spec/supplemental` (Supplemental Specifications)

This directory contains supplemental specification documents.

## Status

These documents are referenced by the normative core specs and implementation
but are **not** part of the frozen DCP surface. They are useful and
authoritative within their scopes, but do not carry the same promotion
requirements as the core tier.

## Contents

| Document | Description |
| :--- | :--- |
| `deterministic-core-profile-v1.md` | DCP component table — what is frozen/verified (v1.0) |
| `canonfs-spec.md` | CanonFS deterministic filesystem storage model |
| `hanoi-kernel-spec.md` | Hanoi kernel archived reference (non-normative) |
| `axion-policy-grammar.md` | APL grammar and verification targets |
| `constitution.md` | Governance principles and foundational invariants |
| `cpp-mapping.md` | Legacy-to-current C++ API mapping notes |

## Authority

Normative authority hierarchy remains:
`/spec` (core) > `docs/architecture/OVERVIEW.md` > `/docs` > `/book`

Supplemental specs inform but do not override core normative docs.
