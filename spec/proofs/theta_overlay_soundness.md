# Formal Θ-Overlay Soundness Proofs

**Status:** Stable
**Published:** 2026-03-08

This document presents the formal proofs of soundness for the Ethics Overlays (Θ₁–Θ₉) implemented in the T81 Base-81 Ternary Computing Stack, as required by RFC-0000.

## 1. Axioms

1.  **State Space ($\Sigma$):** The system state is drawn from a deterministic space $\Sigma$.
2.  **Transitions ($T$):** The VM state transition function is defined as $T: \Sigma \times I \to \Sigma$, where $I$ is the instruction set.
3.  **Overlays ($\Theta$):** An ethics overlay $\Theta_k$ is a predicate over $\Sigma \times I$ such that $\Theta_k(S, i)$ is true iff executing instruction $i$ from state $S$ violates overlay $k$.
4.  **Hanoi Kernel Enforcement:** The Hanoi Kernel ensures that for any state $S$ and instruction $i$, if $\Theta_k(S, i)$ is true for any active overlay $k$, the transition is aborted and the system halts (`AXHALT`).

## 2. Theorem: Strong Soundness of $\Theta$-Containment

**Theorem:** A state sequence $(S_0, S_1, \dots, S_n)$ generated by the Hanoi Kernel will never contain a transition $(S_m, i_m) \to S_{m+1}$ such that $\Theta_k(S_m, i_m)$ is true for any active $k$.

**Proof:**
1.  **Base Case ($n=0$):** The initial state $S_0$ is established by `Kernel::boot()`, which verifies ethics overlays before spawning any processes. Thus, no active overlay is violated at $S_0$.
2.  **Inductive Step:** Assume the sequence up to $S_m$ contains no violations. Consider the next transition attempt: $T(S_m, i_m)$.
3.  The Hanoi Kernel, by Axiom 4, evaluates $\Theta_k(S_m, i_m)$ for all active $k$ prior to committing the transition.
4.  If $\Theta_k(S_m, i_m)$ is true for any $k$, the Kernel issues an `AXHALT` and prevents the transition to $S_{m+1}$. Thus, the resulting sequence $(S_0, \dots, S_m)$ remains violation-free.
5.  If $\Theta_k(S_m, i_m)$ is false for all $k$, the transition $T(S_m, i_m)$ proceeds, resulting in a new state $S_{m+1}$ that, by definition, was reached without violating any active overlay.
6.  Therefore, by mathematical induction, no sequence generated by the Kernel can contain an ethics overlay violation. $\blacksquare$

## 3. Corollary: Tier Promotion Safety

**Corollary:** Tier promotion (e.g., Tier 5 $\to$ Tier 6) preserves the soundness of $\Theta$-Containment.

**Proof:**
1.  Tier promotion activates an additional set of overlays (e.g., adding $\Theta_7$). Let the new set of active overlays be $K' = K \cup \{7\}$.
2.  Any subsequent transition $T(S, i)$ must now satisfy $\forall k \in K': \neg\Theta_k(S, i)$.
3.  Since $K \subset K'$, satisfying the new condition strictly implies satisfying the old condition ($\forall k \in K: \neg\Theta_k(S, i)$).
4.  Therefore, tier promotion monotonically increases the constraints on transitions, preserving all prior guarantees of soundness. $\blacksquare$
